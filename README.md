# Crypto Intelligence OS

**Project status:** Bootstrap v0.1 — activated  
**Owner:** Han  
**Interface:** Telegram first → Web dashboard later  
**Execution:** Research/alerts only in Phase 1; no autonomous trading  
**Style:** Degen / early discovery / evidence-first

## Mission

Build a 24/7 crypto intelligence system that detects information and on-chain behavior before it becomes broadly visible.

The system covers the whole crypto ecosystem:

- Tokens and new launches
- Memecoins
- DeFi
- NFTs
- Launchpads
- DEXs
- Major protocols
- Emerging narratives
- New chains/ecosystems
- On-chain wallet behavior
- Social and news catalysts
- Airdrops / incentives
- Security incidents / exploits
- Governance / upgrades
- Liquidity and capital flows

The system is not a trading bot in Phase 1. It is an intelligence and early-warning system.

## Core loop

DATA → DETECT → VERIFY → RESEARCH → SCORE → ALERT → RECORD OUTCOME → LEARN

## Initial product modules

1. Alpha Radar
2. Wallet Hunter
3. Narrative Radar
4. New Token / Launch Radar
5. Market & Ecosystem Scanner
6. Coin / Protocol Researcher
7. Risk & Scam Filter
8. Source Intelligence
9. Alert Engine
10. Historical Signal Database

## Operating target

Minimum target: 10 useful alerts/day.

Important: 10 alerts means 10 alerts with information value, not 10 arbitrary notifications. The system may send more during high-activity periods and fewer during quiet periods if a quality gate prevents noise.

## Phase 1 restrictions

- No real portfolio required.
- No automatic trade execution.
- No private keys.
- No withdrawal permissions.
- No exchange trading permissions.
- No secrets committed to GitHub.
